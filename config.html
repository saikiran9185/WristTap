2Motion sensors: directionsnot set

Do these in order. Each one counts down 3 s so you can get into the pose, then measures for 2 s. Watch the 3D arm on the right: after all 5 it should move like your arm.

3Hand directions: cursor, flicks, scrollnot set

Hold your hand in the air like holding a mouse. These three moves set which way is right, up and roll: the air-mouse cursor, the slide flicks and the scrolling all use them.

SpeedHow far the cursor moves per turn.
Dead zoneTurns slower than this are ignored, so a resting hand keeps the cursor still.
Test itMoves the real cursor. Needs Accessibility permission for the terminal.

4Squeeze sensors (FSR)not set

The two pressure strips on the forearm. The big numbers are live (0 = no pressure, 4095 = maximum). For each strip: measure it resting, then a light squeeze, then a hard squeeze. The threshold is set halfway between resting and your light squeeze.
